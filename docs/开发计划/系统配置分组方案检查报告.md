## 二、文档概述

**分组设计原则**：
1. **公开配置** - 可被所有租户读取
2. **私有配置** - 仅租户私有
3. **系统级配置** - 仅平台管理员可修改

**统一租户优先级机制**（适用于所有配置分组）：
- 优先读取同租户的私有配置（`IsPublic=false && TenantId=当前租户`）
- 其次读取公开配置（`IsPublic=true`）
- 配置修改后实时生效，无需重启服务

**文件**：`src/Admin/mes-admin/src/views/system/system-configs/index.vue`

- 分组标签页切换（System、Security、AuditLog、Upload）
- 配置列表展示（支持键值搜索、分组筛选）
- 新增/编辑/删除配置功能
- JSON 格式配置支持
- Logo 图片上传功能（Base64 编码）

### 3.3 配置读取服务 ✅

**文件**：
- `ISystemConfigService.cs` - 服务接口
- `SystemConfigService.cs` - 服务实现

**核心方法**：
- `GetValueAsync()` - 获取单个配置值
- `GetBoolAsync()` - 获取布尔类型配置
- `GetIntAsync()` - 获取整数类型配置
- `GetGroupConfigsAsync()` - 按分组获取配置字典（自动应用租户优先级）
- `GetSystemConfigsAsync()` - 获取 System 分组配置（自动应用租户优先级）
- `GetSecurityConfigsAsync()` - 获取 Security 分组配置（自动应用租户优先级）

**重要**：`GetSystemConfigsAsync()` 和 `GetSecurityConfigsAsync()` 现在也会根据当前登录用户的租户ID自动应用租户优先级，确保各租户可以覆盖自己的私有配置。

## 四、审计日志配置应用详情

### 4.1 已实现功能

| 配置键 | 应用位置 | 实现说明 |
|--------|---------|---------|
| `EnableAuditLog` | `AuditLogMiddleware` | `false` 时完全跳过审计日志记录 |
| `EnableLoginAudit` | `AuditLogsController`<br>`InternalAuthController` | `false` 时跳过登录/登出日志记录 |
| `AuditLogRetentionDays` | `AuditLogsController` | 清理过期日志时计算删除日期 |
| `AuditLogExcludePaths` | `AuditLogMiddleware` | 逗号分隔，支持动态配置 |

### 4.2 调用示例

```csharp
// 注入服务
private readonly ISystemConfigService _configService;

// 获取配置（自动处理租户优先级）
var isEnabled = await _configService.GetBoolAsync("EnableAuditLog", true, tenantId);
var retentionDays = await _configService.GetIntAsync("AuditLogRetentionDays", 30, tenantId);
var excludePaths = await _configService.GetValueAsync("AuditLogExcludePaths", "", tenantId);
```

| `PasswordRequireNumber` | `usePasswordPolicy.ts` | 必须包含数字(0-9)校验 |
| `PasswordRequireSpecialChar` | `usePasswordPolicy.ts` | 必须包含特殊字符校验 |

### 6.2 代码文件

| 文件 | 说明 |
|------|------|
| `src/Admin/mes-admin/src/composables/usePasswordPolicy.ts` | 密码策略 Composable，统一提供策略加载、提示文字生成、表单验证 |
| `src/Admin/mes-admin/src/views/system/profile/index.vue` | 个人中心修改密码功能，集成密码策略 |

### 6.3 调用示例

```typescript
import { usePasswordPolicy } from '@/composables/usePasswordPolicy'

const { loadPolicy, getPolicyText, getPasswordRules, validatePassword } = usePasswordPolicy()

// 页面加载时获取密码策略
onMounted(() => {
  loadPolicy()
})

// 获取格式化的密码要求提示
const policyTip = getPolicyText()
// 例如: "密码长度8-32位，必须包含大写字母(A-Z)、小写字母(a-z)、数字(0-9)、特殊字符(!@#$等)"

// 获取 Element Plus 表单验证规则
const rules = [getPasswordRules()]

// 手动验证密码
const { valid, errors } = validatePassword(password)
```

### 6.4 动态组合特性

密码策略 Composable 从 API 动态读取 Security 分组的实际配置项，根据配置值运行时组合提示文字：
- 管理员可在配置管理中增删配置项，提示文字自动适应
- 无任何密码策略配置时，不显示提示信息
