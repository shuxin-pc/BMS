# BMS系统环境配置说明

## 概述

本文档说明如何在不同环境（开发/测试/生产）中配置 BMS 系统。

---

## 功能开关配置 (Feature Flags)

所有功能开关在 `appsettings.json` 的 `FeatureFlags` 节点中配置。

### 1. UseHttpsRedirection

是否强制 HTTPS 重定向。

| 环境 | 推荐值 | 说明 |
|------|--------|------|
| 开发环境 | `false` | 避免 HTTP 请求被重定向，方便调试 |
| 生产环境 | `true` | 强制 HTTPS，保证传输安全 |

```json
{
  "FeatureFlags": {
    "UseHttpsRedirection": false
  }
}
```

---

## CORS 配置

配置允许访问 API 的前端域名。

### 开发环境

配置前端开发服务器地址：

```json
{
  "Cors": {
    "AllowedOrigins": [
      "http://localhost:5173",
      "http://localhost:3000"
    ]
  }
}
```

### 生产环境

配置生产环境的前端域名：

```json
{
  "Cors": {
    "AllowedOrigins": [
      "https://mes.yourcompany.com",
      "https://admin.mes.yourcompany.com"
    ]
  }
}
```

**注意**：如果 `AllowedOrigins` 为空数组，系统会允许任意来源（不推荐生产环境使用）。

## 服务端口分配

| 服务 | HTTP | HTTPS | 说明 |
|------|------|-------|------|
| System.Api | 5000 | 5001 | 系统管理服务 |
| Identity.Api | 5010 | 5011 | 认证授权服务 |
| Gateway.Api | 5020 | 5021 | API网关 |

### 开发环境

可以直接访问各服务的 HTTP 端口：
- System.Api: `http://localhost:5000`
- Identity.Api: `http://localhost:5010`

### 生产环境

通过网关 HTTPS 访问：
- Gateway: `https://mes-api.yourcompany.com`

## 数据库配置

### 连接字符串

```json
{
  "ConnectionStrings": {
    "SystemDb": "Host=localhost;Port=5432;Database=bms_system;Username=postgres;Password=yourpassword",
    "IdentityDb": "Host=localhost;Database=bms_identity;Username=postgres;Password=yourpassword"
  }
}
```

### 数据库迁移

系统启动时会自动执行 EF Core 迁移：

- **System.Api**: 初始化 `bms_system` 数据库和种子数据
- **Identity.Api**: 初始化 `bms_identity` 数据库（OpenIddict 令牌表）

---

## 前端 API 配置

前端根据环境自动选择 API 地址：

### 开发环境

直接访问服务端口：
- System.Api: `http://localhost:5000/api/system`
- Identity.Api: `http://localhost:5010`

### 生产环境

通过网关访问：
- System.Api: `/api/system`
- Identity.Api: `/api/identity`

---

## OpenIddict 配置

### 开发环境

使用临时开发证书：
```csharp
if (builder.Environment.IsDevelopment())
{
    options.AddDevelopmentEncryptionCertificate()
           .AddDevelopmentSigningCertificate();
}
```

### 生产环境

应该使用真实的签名证书，配置方式见 OpenIddict 官方文档。

## 环境配置文件说明

| 文件名 | 说明 |
|--------|------|
| `appsettings.json` | 基础配置（所有环境共用） |
| `appsettings.Development.json` | 开发环境特定配置（覆盖基础配置） |
| `appsettings.Production.json` | 生产环境特定配置（覆盖基础配置） |

## 环境变量

也可以使用环境变量覆盖配置：

```bash
# Windows
set FeatureFlags__UseHttpsRedirection=true
set Cors__AllowedOrigins__0=https://mes.yourcompany.com

# Linux/Mac
export FeatureFlags__UseHttpsRedirection=true
export Cors__AllowedOrigins__0=https://mes.yourcompany.com
```

## 快速开始

### 开发环境启动

1. 确保 PostgreSQL 正在运行
2. 启动 System.Api:
   ```bash
   cd src/Services/System/Bms.System.Api
   dotnet run --launch-profile http
   ```
3. 启动 Identity.Api:
   ```bash
   cd src/Services/Identity/Bms.Identity.Api
   dotnet run --launch-profile http
   ```
4. 启动前端:
   ```bash
   cd src/Admin/mes-admin
   npm run dev
   ```

### 访问登录页面

- 前端地址: `http://localhost:5173`
- 登录凭据: `admin` / `Admin@123`

---

## 注意事项

1. **HTTPS 重定向**: 生产环境务必启用 `UseHttpsRedirection`
2. **CORS 配置**: 生产环境务必配置具体的 `AllowedOrigins`，不要留空
3. **数据库密码**: 生产环境使用强密码，不要提交到代码仓库
4. **OpenIddict 证书**: 生产环境使用真实的签名证书，不要使用开发证书
