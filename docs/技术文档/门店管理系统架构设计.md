# 门店管理系统 - 架构设计文档

> 版本: v1.0 | 日期: 2026-07-11 | 状态: 初稿

---

## 一、项目概述

### 1.1 背景

门店管理系统是 BMS 平台的核心业务系统之一，主要服务于美容行业门店的日常运营管理。系统需要支持多门店、多租户的业务模式，并复用 BMS 平台现有的用户体系和权限管理能力。

### 1.2 设计目标

- 支持 1 租户 → N 门店的业务模式
- 门店业务数据与基础数据（用户、角色、菜单）分离存储
- 通过行级隔离（TenantId）实现多租户数据隔离
- 保持与现有 System 服务的一致性

## 三、数据库架构

### 3.1 数据库分配

| 服务 | 数据库 | Schema | 用途 |
|-----|-------|--------|-----|
| System | `bms_system` | `bms_system` | 租户、用户、角色、菜单、系统配置 |
| Store | `bms_store` | `bms_store` | 门店、商品、库存、订单、会员等业务数据 |

### 3.2 隔离策略

- **多租户隔离**：行级隔离（TenantId），所有业务实体继承 `TenantEntity` 基类
- **数据库隔离**：System 与 Store 服务各自独立数据库，符合微服务"数据库自治"原则

### 3.3 实体基类

```csharp
// TenantEntity 基类（继承自 BaseEntity + ITenant）
public abstract class TenantEntity : BaseEntity, ITenant
{
    public long TenantId { get; set; }
    public string TenantCode { get; set; } = string.Empty;
}
```

所有门店业务实体（如 Store、Product、Order 等）均继承 `TenantEntity`。

## 四、服务间通信

### 4.1 通信架构

```
┌─────────────┐         ┌─────────────┐
│  Store.Api  │ ──HTTP──▶ │  System.Api │
│             │ ◀──JWT── │  (获取用户)  │
└─────────────┘         └─────────────┘
         │
         ▼
┌─────────────┐
│ Identity.Api│  (JWT 验证)
└─────────────┘
```

### 4.2 用户体系

- **门店用户登录**：通过 Identity 服务统一认证，获取 JWT Token
- **用户信息获取**：Store 服务调用 System 服务 API 获取用户信息、菜单权限
- **租户授权控制**：TenantSubsystem 关联表控制租户是否有权使用门店系统

### 4.3 服务调用约定

Store 服务需要调用 System 服务获取以下数据：

| 接口 | 用途 |
|-----|-----|
| GET /api/system/users/{id} | 获取用户基本信息 |
| GET /api/system/menus/subsystem/{subsystemCode} | 获取子系统菜单 |
| GET /api/system/roles/{id}/permissions | 获取角色权限 |

## 九点一、菜单自注册机制

### 9.1.1 设计背景

Store 服务独立管理自己的菜单数据，通过调用 System 服务 API 完成菜单注册，而不是在 System 服务中硬编码。

### 9.1.2 实现方案

1. **StoreMenuSeedData**：定义门店管理系统所有菜单结构（33个菜单）
2. **StoreMenuRegistrationService**：IHostedService，在应用启动时自动执行
3. **内部服务调用认证**：使用 Header 认证机制（X-Internal-Service + X-Internal-Service-Key）

### 9.1.3 注册流程

```
Store 服务启动
    ↓
检查子系统是否已存在（GET /api/system/subsystems/list-all）
    ↓
如果不存在：
    1. 创建子系统（POST /api/system/subsystems）
    2. 创建菜单（POST /api/system/menus）
    3. 分配菜单给子系统（PUT /api/system/subsystems/{id}/menus）
    4. 分配子系统给平台租户（POST /api/system/tenants/1/subsystems/{subsystemId}）
```

### 9.1.4 内部服务认证配置

| 服务 | 配置项 | 值 |
|-----|-------|-----|
| System | InternalServices:ServiceKey | StoreService-Internal-Key-2026 |
| Store | InternalServices:ServiceName | StoreService |
| Store | InternalServices:ServiceKey | StoreService-Internal-Key-2026 |
