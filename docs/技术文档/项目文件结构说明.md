**版本**：v1.0
**日期**：2026-03-18
**适用范围**：BMS系统开发人员

---

## 项目整体架构

```
Bms/
├── src/                      # 源代码目录
├── templates/                # 项目模板
├── build/                    # 构建配置
├── deploy/                   # 部署配置
├── docs/                     # 项目文档
├── Bms.sln                   # 解决方案文件
└── Directory.Build.props     # 全局构建配置
```

---

## 1. src/ - 源代码目录

### 1.1 BuildingBlocks/ （公共模块/基础设施层）

| 项目 | 说明 |
|------|------|
| `Bms.BuildingBlocks.Abstractions` | 抽象层 - 定义接口、基类、通用DTO |
| `Bms.BuildingBlocks.Core` | 核心模块，包含：<br>- Extensions（扩展方法）<br>- HealthChecks（健康检查）<br>- ServiceDiscovery（服务发现） |
| `Bms.BuildingBlocks.MultiTenant` | 多租户支持：<br>- Abstractions、Data、Middleware<br>- Models、Resolvers、Services、Stores |
| `Bms.BuildingBlocks.Web` | Web基础模块 - 通用Web功能 |

### 1.2 Services/ （业务服务层）

| 项目 | 说明 |
|------|------|
| `Bms.Identity.Api` | 身份认证服务 - 用户认证、授权、令牌管理 |

### 1.3 Gateway/ （网关层）

| 项目 | 说明 |
|------|------|
| `Bms.Gateway.Api` | API网关 - 请求路由、负载均衡、限流 |

### 1.4 Admin/ （前端管理后台）

| 项目 | 说明 |
|------|------|
| `mes-admin` | Vue 3 + TypeScript + Element Plus 管理后台 |

## 备注

这是一个典型的微服务架构系统，采用 DDD（领域驱动设计）思想分层：
- **BuildingBlocks**: 公共基础设施层，被所有服务引用
- **Services**: 业务服务层，各微服务独立部署
- **Gateway**: 网关层，统一入口
- **Admin**: 前端管理界面

当前包含：身份认证服务、API网关、管理后台前端。
