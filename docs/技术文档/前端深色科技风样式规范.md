# BMS系统 前端深色科技风样式规范

> 本文档基于 `src/Admin/mes-admin/src/styles/dark-theme.css` v2.0 实际样式编写，与项目运行效果保持一致。

## 一、设计原则
- **深色基调**：以深色背景为主，减少视觉疲劳，突出数据和内容
- **青色高亮**：使用青色作为主色调，体现科技感和现代感
- **层级分明**：通过背景色深浅区分不同功能区块，提升界面层次感
- **高对比度**：文字与背景保持足够对比度，确保内容清晰可读
- **发光效果**：关键元素使用发光边框和阴影，增强科技感

## 四、组件规范

### 1. 输入框
| 状态 | 背景色 | 边框色 |
|------|--------|--------|

| 普通按钮 | `--bg-tertiary` | `--border-primary` | `--text-secondary` |

- 阴影：`var(--shadow-md)`
- 悬浮：边框变亮 + `var(--shadow-lg)` + 顶部发光线条

## 七、开发规范

### 1. 样式引入
所有页面统一引入 `@/styles/dark-theme.css`。

### 2. 变量使用
所有颜色必须使用 CSS 变量，禁止硬编码色值：
```css
/* 正确 */
background-color: var(--bg-tertiary);
color: var(--text-primary);

/* 错误 */
background-color: #1a2332;
color: #e8f4f8;
```

### 3. 组件覆盖
如需覆盖 Element Plus 组件样式，统一在 `dark-theme.css` 中全局处理，特殊情况可在组件内使用 `:deep()` 覆盖。

### 4. 响应式
- 桌面端优先，适配 1920×1080 及以上分辨率
- 侧边栏宽度：展开 200px，折叠 64px
- 内容区域最小宽度：1200px
