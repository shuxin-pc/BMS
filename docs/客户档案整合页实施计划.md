# 服务档案整合页实施计划

> **给实施者：** 本计划配合 superpowers:subagent-driven-development 或 superpowers:executing-plans 执行。步骤使用复选框（`- [ ]`）语法跟踪进度。
>
> **设计依据：** `docs/客户档案整合页设计.md`

**目标：** 将美容档案、体型数据、反应记录、照片管理 4 个独立菜单页面整合为单一"服务档案"菜单，页面内以选项卡切换，4 个选项卡共享同一"当前客户"上下文。

**架构：** 一个容器组件负责客户选择、选项卡权限过滤与懒加载；4 个面板子组件各自接收 `customerId` / `customerName` prop 并自行管理数据加载与写操作。后端零改动（4 个查询接口已支持 `CustomerId` 过滤）。选项卡权限复用现有 `Type=2` 按钮权限机制。

**技术栈：** Vue 3 + TypeScript + Element Plus；后端 .NET 8 种子数据（`StoreMenuSeedData.cs`、`SystemSeedData.cs`、`TestSeedData/*.json`）。

## 验证方式说明

本项目无前端测试框架、无后端测试项目，故不采用 TDD。此外**`npm run lint` 在本仓库不可用**：`package.json` 声明了该脚本，但 eslint 不在 `devDependencies`、未安装于 `node_modules`、且无配置文件，执行会直接报"eslint 不是内部或外部命令"。为一次 UI 整合引入 eslint 属超出需求的改动，本次不引入。

因此每个任务的验证手段为两层：

- **类型检查**：`npm run build`（内含 `vue-tsc`）
- **手工验收**：每个任务末尾给出明确的浏览器验收步骤与预期结果

### Task 2：创建容器组件骨架

容器只负责三件事：选客户、按权限过滤选项卡、选项卡懒加载。此任务先用占位内容验证骨架与权限逻辑，面板在 Task 4-7 逐个接入。

**Files:**
- Create: `src/Admin/mes-admin/src/views/store/customer/archive/index.vue`

- [ ] **Step 1：创建容器组件**

关键设计点（照抄下方代码即可满足，但需理解为何这样写）：

1. `tabDefinitions` 的 `component` 字段类型为 `Component | null`，`null` 表示该面板尚未接入，模板回落到占位 `<div>`。**这是 Task 4-7 增量接入的关键**：若不留 `null` 态，接入第一个面板时其余三个的字符串占位会让 `<component :is>` 解析失败——`npm run build` 不报错，浏览器里静默渲染成空元素，问题会潜伏到 Task 7 才暴露。
2. 用 `selectedCustomer` computed 而非裸 `currentCustomerId` 向下传值。这样一次拿到 `id`（number）和 `name`（string），既满足面板的 `customerName` 需求，又避免 `number | undefined` 在模板里向必填 `number` prop 传值的类型收窄问题。
3. `activeTab` 用 `watch(..., { immediate: true })` 而非 `onMounted` 赋值，并在当前激活项落到 `visibleTabs` 之外时重置。这样"默认激活第一个有权限的选项卡"只有一个同步入口，`visibleTabs` 后续若因权限变化而改变，激活项会自动跟上，不会停留在一个已无权限的选项卡上。

   注意：权限在组件挂载前就已就位——`main.ts:28-33` 在 `app.use(router)` **之前** 就 `await userStore.getUserInfo()` / `getMenus()`。因此 `onMounted` 里读 `visibleTabs.value` 是可靠的，下方代码用它来门控 `loadCustomers()` 是正确的。**不要**因为"权限可能还没加载"去改动这个门控。

```vue
<template>
  <div class="customer-archive">
    <!-- 无任何选项卡权限：整页空态，避免打开成空壳 -->
    <div v-if="visibleTabs.length === 0" class="card">
      <el-empty description="暂无可查看的档案内容，请联系管理员分配权限" />
    </div>

    <template v-else>
      <!-- 客户上下文选择区：4 个选项卡共享此选择结果 -->
      <div class="card mb-20">
        <div class="customer-selector">
          <span class="selector-label">客户</span>
          <el-select
            v-model="currentCustomerId"
            placeholder="请选择客户"
            filterable
            clearable
            :loading="customerLoading"
            style="width: 280px"
          >
            <el-option
              v-for="item in customerOptions"
              :key="item.id"
              :label="`${item.name}（${item.phone}）`"
              :value="item.id"
            />
          </el-select>
        </div>
      </div>

      <!-- 选项卡区 -->
      <div class="card">
        <el-tabs v-model="activeTab">
          <el-tab-pane
            v-for="tab in visibleTabs"
            :key="tab.name"
            :label="tab.label"
            :name="tab.name"
          >
            <el-empty v-if="!selectedCustomer" description="请先在上方选择客户" />
            <!-- 懒加载：仅渲染当前激活的面板，避免一次并发 4 个请求 -->
            <template v-else-if="activeTab === tab.name">
              <component
                v-if="tab.component"
                :is="tab.component"
                :customer-id="selectedCustomer.id"
                :customer-name="selectedCustomer.name"
              />
              <div v-else class="tab-placeholder">{{ tab.label }}面板待接入</div>
            </template>
          </el-tab-pane>
        </el-tabs>
      </div>
    </template>
  </div>
</template>

<script setup lang="ts">
import { ref, computed, watch, onMounted, type Component } from 'vue'
import { ElMessage } from 'element-plus'
import { useUserStore } from '@/stores/user'
import { getCustomerOptions } from '@/api/customer-profile'
import type { CustomerOption } from '@/api/customer-profile/types'

const userStore = useUserStore()

/** 当前选中的客户ID，作为 4 个面板的共享上下文 */
const currentCustomerId = ref<number | undefined>(undefined)
const customerOptions = ref<CustomerOption[]>([])
const customerLoading = ref(false)

/** 选中的客户对象；面板需要 name 做只读展示，故整体下传而非只传 id */
const selectedCustomer = computed(() =>
  customerOptions.value.find(c => c.id === currentCustomerId.value)
)

interface TabDefinition {
  name: string
  label: string
  permission: string
  /** 面板组件；null 表示尚未接入，渲染占位内容 */
  component: Component | null
}

/**
 * 选项卡定义与权限映射
 * 系统权限只有目录/菜单/按钮三级，选项卡级控制依托 Type=2 按钮权限实现
 */
const tabDefinitions: TabDefinition[] = [
  { name: 'beauty', label: '美容档案', permission: 'store:customer:archive:beauty', component: null },
  { name: 'bodyData', label: '体型数据', permission: 'store:customer:archive:body-data', component: null },
  { name: 'reaction', label: '反应记录', permission: 'store:customer:archive:reaction', component: null },
  { name: 'photo', label: '照片管理', permission: 'store:customer:archive:photo', component: null }
]

/** 当前用户有权查看的选项卡 */
const visibleTabs = computed(() =>
  tabDefinitions.filter(tab => userStore.hasPermission(tab.permission))
)

const activeTab = ref('')

/** 默认激活第一个有权限的选项卡，与 visibleTabs 保持单一同步入口 */
watch(
  visibleTabs,
  tabs => {
    if (tabs.length === 0) {
      activeTab.value = ''
      return
    }
    if (!tabs.some(t => t.name === activeTab.value)) {
      activeTab.value = tabs[0].name
    }
  },
  { immediate: true }
)

const loadCustomers = async () => {
  customerLoading.value = true
  try {
    customerOptions.value = await getCustomerOptions()
  } catch (error) {
    ElMessage.error('加载客户列表失败')
  } finally {
    customerLoading.value = false
  }
}

onMounted(() => {
  // 无任何选项卡权限时页面只显示空态，无需拉客户列表
  if (visibleTabs.value.length > 0) {
    loadCustomers()
  }
})
</script>

}
```

- [ ] **Step 2：正式种子数据新增授权方法**

在 `SystemSeedData.cs:402` 的 `EnsureProductMasterMenuAuths` 方法结束后（`}` 之后、`AddConfigIfNotExists` 注释之前）插入以下**完整方法**。该方法体是 `EnsureProductMasterMenuAuths` 的逐行复制，仅 `targetCodes` 与注释不同：

```csharp
    /// <summary>
    /// 为超级管理员授权服务档案相关菜单（4 页面整合改造新增）
    /// 授权范围：服务档案页面菜单 + 4 个选项卡查看按钮
    /// 页面查看按钮（:view）由 EnsurePageViewButtons 自动创建并授权，此处不重复
    /// 幂等，可安全重复调用，用于已有数据库的增量补全
    /// </summary>
    public static void EnsureCustomerArchiveMenuAuths(SystemDbContext context)
    {
        var superAdminRole = context.Roles.FirstOrDefault(r => r.Code == "super_admin" && !r.IsDeleted);
        if (superAdminRole == null)
        {
            return;
        }

        // 目标菜单 Code（不含 :view 按钮，由 EnsurePageViewButtons 处理）
        var targetCodes = new[]
        {
            "store:customer:archive",
            "store:customer:archive:beauty",
            "store:customer:archive:body-data",
            "store:customer:archive:reaction",
            "store:customer:archive:photo"
        };

        var menus = context.Menus
            .Where(m => targetCodes.Contains(m.Code) && !m.IsDeleted)
            .ToList();
        if (menus.Count == 0)
        {
            return;
        }

        var existingMenuIds = context.RoleMenuAuths
            .Where(rma => rma.RoleId == superAdminRole.Id)
            .Select(rma => rma.MenuId)
            .ToHashSet();

        // 查询菜单所属子系统映射
        var menuIds = menus.Select(m => m.Id).ToList();
        var subsystemMap = context.SubsystemMenus
            .Where(sm => menuIds.Contains(sm.MenuId))
            .ToDictionary(sm => sm.MenuId, sm => sm.SubsystemId);

        var now = DateTime.Now;
        var hasChanges = false;

        foreach (var menu in menus)
        {
            if (existingMenuIds.Contains(menu.Id))
            {
                continue;
            }

            subsystemMap.TryGetValue(menu.Id, out var subsystemId);

            context.RoleMenuAuths.Add(new RoleMenuAuth
            {
                RoleId = superAdminRole.Id,
                MenuId = menu.Id,
                SubsystemId = subsystemId,
                CreatedTime = now
            });
            hasChanges = true;
        }

        if (hasChanges)
        {
            context.SaveChanges();
        }
    }
```
