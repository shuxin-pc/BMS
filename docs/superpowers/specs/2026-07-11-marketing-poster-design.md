# 营销宣传图片生成功能设计

> 版本: v1.0 | 日期: 2026-07-11 | 状态: 待评审

## 一、背景与目标

### 背景
《通用需求规格》G6「营销管理」章节中，优惠活动的设计方案不明确。实体门店缺少实体优惠券等纸质卡券，需要提供能在系统中实际推行的宣传方案。

### 目标
- 系统提供预设的宣传模板，商户填入活动内容
- 系统生成可预览、可下载的宣传图片
- 图片支持清晰打印（多尺寸：A4、A5、朋友圈竖版、手机壁纸）

---

## 二、功能范围

### 2.1 核心功能

| 编号 | 功能 | 说明 |
|------|------|------|
| F1 | 模板选择 | 提供5-8种预设风格模板，商户选择后进入编辑 |
| F2 | 内容编辑 | 商户自定义标题、描述、日期、颜色、图片等 |
| F3 | 实时预览 | 编辑时实时显示海报效果 |
| F4 | 图片导出 | 生成PNG图片，支持多尺寸下载 |
| F5 | 模板复用 | 历史生成的模板可保存为草稿，下次修改使用 |

### 2.2 非功能范围

- 不涉及优惠券核销（由其他模块处理）
- 不涉及支付和订单关联
- 不涉及消息推送

## 三、技术方案

### 3.1 架构选择

**纯前端方案（推荐）**

所有生成逻辑在前端完成，不依赖后端图片渲染服务。

| 组件 | 技术选型 |
|------|---------|
| 前端框架 | Vue 3 + TypeScript（与现有前端一致）|
| 海报绘制 | Canvas API + html2canvas |
| 图片导出 | 浏览器原生下载（a.download）|
| 草稿存储 | localStorage（当前设备）|

**优势：**
- 零服务器资源消耗
- 即用即生成，无延迟
- 运维成本极低，适合轻量运营门店

**劣势：**
- 跨设备无法同步历史模板（需手动导出备份）

### 3.2 模板数据结构

```typescript
interface PosterTemplate {
  id: string;
  name: string;                    // 模板名称
  thumbnail: string;              // 缩略图URL
  canvasWidth: number;             // 画布宽度(px)
  canvasHeight: number;            // 画布高度(px)
  dpi: number;                     // 打印分辨率
  elements: TemplateElement[];     // 元素列表
}

interface TemplateElement {
  id: string;
  type: 'text' | 'image' | 'shape' | 'qrcode';
  x: number;                      // X坐标(px)
  y: number;                       // Y坐标(px)
  width: number;                   // 宽度(px)
  height: number;                  // 高度(px)
  styles: Record<string, string>;  // 样式（字体、颜色等）
  editable: boolean;               // 商户是否可编辑
  defaultValue?: string;           // 默认值
}
```

### 3.3 尺寸规格

| 尺寸名称 | 用途 | 分辨率(px) | DPI | 打印尺寸 |
|---------|------|-----------|-----|---------|
| A4 | 门店张贴/打印 | 2480 × 3508 | 300 | 210 × 297mm |
| A5 | 小海报/收银台 | 1748 × 2480 | 300 | 148 × 210mm |
| 朋友圈竖版 | 微信分享 | 1080 × 1920 | 72 | 屏幕版 |
| 手机壁纸 | 手机展示 | 1080 × 2340 | 72 | 屏幕版 |

### 6.2 草稿保存

- 每30秒自动保存到 localStorage
- 退出编辑时提示保存草稿
- 重新进入时检测草稿并询问是否恢复

### 6.3 图片导出流程

```
用户点击下载
    ↓
检查画布分辨率是否匹配尺寸
    ↓
Canvas.toBlob() 生成 PNG
    ↓
创建隐藏的 <a download="海报.png"> 触发下载
    ↓
提示下载成功
```

## 七、打印质量保证

### 7.1 分辨率设置

| 尺寸 | 屏幕版DPI | 打印版DPI | 说明 |
|------|----------|----------|------|
| A4 | 72 | 300 | 供打印使用 |
| A5 | 72 | 300 | 供打印使用 |
| 朋友圈竖版 | 72 | - | 仅屏幕显示 |
| 手机壁纸 | 72 | - | 仅屏幕显示 |

### 7.2 字体处理

- 预设字体列表：中文字体优先使用系统自带（思源黑体、苹方等）
- 字体文件过大时不嵌入，依赖用户系统字体
- 关键文字使用路径文字（convertToPath）确保打印一致性

### 7.3 图片质量

- 商户上传图片时限制最小分辨率（至少为目标尺寸的1.5倍）
- 图片自动压缩到合适大小，防止Canvas性能问题
- 支持 JPEG 背景图（文件更小）

## 十二、风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| Canvas 跨域图片无法绘制 | 中 | 上传图片时强制转换为 base64 |
