## 3. 登录流程

- 前端登录页：`src/Admin/mes-admin/src/views/login/index.vue`
- 登录接口验证用户名和密码，成功后返回用户信息和权限
- 系统根据角色分配对应的菜单和操作权限
- 密码验证逻辑位于 `AuthAppService.ValidateUserAsync` 方法
