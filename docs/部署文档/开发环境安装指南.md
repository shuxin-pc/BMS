## 🔧 详细安装步骤

### 1. .NET 8 SDK 安装

**检查是否已安装**：
```bash
dotnet --version
```
预期输出：`8.0.xxx` 或更高版本

**安装步骤**：
1. 访问官方下载地址：https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0
2. 选择对应系统的安装包：
   - Windows：下载 `x64` 或 `x86` Installer
   - macOS：下载对应芯片架构的安装包
   - Linux：参考官网对应发行版的安装命令
3. 运行安装程序，按照向导提示完成安装
4. 重启终端，重新运行检查命令验证安装成功

**验证安装**：
```bash
dotnet --info
```
确认SDK版本为8.0.x系列

---

### 2. Node.js + npm 安装

**检查是否已安装**：
```bash
node --version
npm --version
```
预期输出：
- Node.js >= v18.17.0
- npm >= 9.6.7

**安装步骤**：
1. 访问官方下载地址：https://nodejs.org/zh-cn/
2. 下载 **LTS 长期支持版本**（推荐20.x系列）
3. 运行安装程序，安装选项保持默认即可
   - 确保勾选 "Add to PATH" 选项
4. 重启终端，验证版本信息

**可选配置**：设置npm镜像源加速
```bash
# 淘宝镜像源（推荐国内用户）
npm config set registry https://registry.npmmirror.com/

# 验证配置
npm config get registry
```

---

### 3. Docker Desktop 安装

**检查是否已安装**：
```bash
docker --version
docker-compose --version
```
预期输出：
- Docker version >= 24.0.0
- Docker Compose version >= v2.20.0

**安装步骤（Windows）**：
1. 访问官方下载地址：https://www.docker.com/products/docker-desktop/
2. 下载Windows版本安装包
3. 运行安装程序，注意勾选以下选项：
   - ✅ "Use WSL 2 instead of Hyper-V"
   - ✅ "Add shortcut to desktop"
4. 安装完成后重启电脑
5. 首次启动Docker Desktop，同意服务条款
6. 在设置中确认：
   - General → ✅ "Use the WSL 2 based engine"
   - Resources → WSL Integration → 开启你使用的WSL发行版（如果使用WSL）

**验证安装**：
```bash
docker run hello-world
```
如果成功运行并输出欢迎信息，说明安装成功

---

### 4. Git 安装

**检查是否已安装**：
```bash
git --version
```
预期输出：`git version 2.xx.x`

**安装步骤**：
1. 访问官方下载地址：https://git-scm.com/download/win
2. 下载64位Git安装包
3. 运行安装程序，关键选项设置：
   - Select Components：建议勾选 "Git Bash Here"、"Git GUI Here"
   - Adjusting your PATH environment：选择 "Git from the command line and also from 3rd-party software"
   - Choosing the SSH executable：选择 "Use bundled OpenSSH"
   - Configuring the line ending conversions：选择 "Checkout Windows-style, commit Unix-style line endings"
   - 其他选项保持默认即可
4. 安装完成后验证版本

**基础配置（首次安装需要）**：
```bash
# 配置用户名
git config --global user.name "你的姓名"

# 配置邮箱
git config --global user.email "你的邮箱地址"

# 查看配置
git config --list
```

### 5. PostgreSQL 安装（可选）

如果不想本地安装，可以直接使用项目中的Docker Compose启动PostgreSQL服务。

**检查是否已安装**：
```bash
psql --version
```
预期输出：`psql (PostgreSQL) 14.x` 或更高版本

**安装步骤**：
1. 访问官方下载地址：https://www.postgresql.org/download/windows/
2. 下载PostgreSQL 16.x版本安装包
3. 运行安装程序：
   - 安装路径建议保持默认
   - 选择组件时建议全部勾选（包含pgAdmin管理工具）
   - 设置超级用户（postgres）密码：建议设置为 `mes@2026` 与项目配置保持一致
   - 端口保持默认 `5432`
   - 区域设置选择 "Chinese (Simplified), China"
4. 安装完成后，可以在开始菜单找到pgAdmin管理工具
5. 打开pgAdmin，连接本地数据库，验证连接正常

```bash

npm --version
```

## ❓ 常见问题

### Q: Docker启动失败，提示WSL 2 installation is incomplete
A: 需要更新WSL2内核，下载地址：https://learn.microsoft.com/zh-cn/windows/wsl/install-manual#step-4---download-the-linux-kernel-update-package

### Q: npm安装依赖速度慢
A: 配置淘宝镜像源：`npm config set registry https://registry.npmmirror.com/`

### Q: Visual Studio安装慢
A: 在安装程序选择安装位置时，可以将缓存路径设置到非系统盘，同时关闭其他占用网络的程序

### Q: PostgreSQL连接失败
A: 检查PostgreSQL服务是否启动，确认端口5432是否被占用，防火墙是否允许连接

安装过程中遇到任何问题，请随时查阅相关官方文档或寻求帮助。
