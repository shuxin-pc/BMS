# 门店管理系统 - 菜单架构

> 版本: v1.0 | 日期: 2026-07-11 | 状态: 已确认

---

## 一、首页

| 菜单项 | 说明 |
|--------|------|
| 经营看板 | 今日营收/订单数/毛利/预警、本月趋势 |

## 二、门店管理

| 菜单项 | 说明 |
|--------|------|
| 门店档案 | 基础信息 + 状态管理 |

## 三、商品管理

| 菜单项 | 说明 |
|--------|------|
| 商品分类 | G2.1 |
| 商品档案 | G2.2 |
| 库存管理 | 入库/出库/盘点/调拨 |
| 库存预警 | G2.4 |
| 价格管理 | G2.5 |
| 供应商管理 | 含档案、采购记录、采购退货 |
| 效期查询 | 库存效期查看 |
| 效期预警 | B5.4 |

## 四、收银管理

| 菜单项 | 说明 |
|--------|------|
| 快速开单 | 支持商品搜索、分类点选、手动输入 |
| 订单管理 | 含退款处理 |

## 五、客户管理

| 菜单项 | 说明 |
|--------|------|
| 客户档案 | 含美容行业扩展档案 |
| 客户等级 | 普通/会员两级 |
| 积分管理 | 积分规则、流水记录 |
| 消费记录 | 消费历史、偏好统计 |
| 客户关怀 | 生日提醒、消费感谢 |

## 六、会员储值

| 菜单项 | 说明 |
|--------|------|
| 储值账户 | 余额、累计充值/消费、赠送金额 |
| 储值规则 | 赠送规则配置 |
| 储值流水 | 每笔储值/消费/退款明细 |

## 七、营销管理

| 菜单项 | 说明 |
|--------|------|
| 宣传图片生成 | 预设模板选择、内容编辑、素材库、实时预览、多尺寸导出（G6.1） |

## 八、预约管理

| 菜单项 | 说明 |
|--------|------|
| 预约日历 | 日/周视图，按技师或房间查看 |
| 预约列表 | 预约确认、状态流转 |
| 明日提醒 | 明日预约确认 |

## 九、疗程卡管理

| 菜单项 | 说明 |
|--------|------|
| 疗程卡配置 | 卡名、项目、次数、有效期 |
| 疗程卡销售 | 购买记录、有效期内自动计算 |
| 疗程卡核销 | 手动核销1次、剩余次数实时可见 |
| 到期提醒 | 即将到期列表 |

## 十、服务人员

| 菜单项 | 说明 |
|--------|------|
| 商家技师 | 技师档案、技能标签 |
| 技师统计 | 服务人次、时长、提成、回头客率 |

## 十一、样品赠品

| 菜单项 | 说明 |
|--------|------|
| 样品赠品档案 | 独立库存、与正品分开管理 |
| 样品领用 | 体验客户领取记录 |
| 赠品出库 | 促销活动关联出库 |
| 库存查询 | 样品/赠品单独库存查看 |
| 统计报表 | 领用/发放数量统计 |

## 模块统计

| 分类 | 一级菜单数 |
|------|-----------|
| 通用模块 | 7 |
| 美容扩展 | 4 |
| **合计** | **11** |

## 设计原则

- 轻量不增加负担，收银即记账，打开即看经营状况
- 美容扩展模块仅美容行业可见
- 平台技师仅读取使用，不做增删改管理
